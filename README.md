## Deskripsi

Project ini merupakan implementasi web scraping menggunakan Scrapy pada website Books to Scrape. Data hasil scraping ditampilkan menggunakan Streamlit dan dapat dilakukan pencarian berdasarkan judul buku.

## Teknologi yang Digunakan

- Python
- Scrapy
- Streamlit
- Pandas

## Fitur

- Melakukan scraping data buku menggunakan Scrapy
- Menyimpan hasil scraping dalam format CSV
- Menampilkan data buku menggunakan Streamlit
- Melakukan pencarian buku berdasarkan judul
